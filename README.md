# پروان دانلود منیجر (Parvan Download Manager)

- **وضعیت:** طراحی و رابط کاربری اولیه تایید در دست بررسی (UI Prototype Saved)
- **مسیر پروژه:** `C:\Users\V I S I O N\parvan-download-manager`
- **فایل اصلی رابط کاربری:** `index.html`
- **امکانات ذخیره شده:**
  - مانیتورینگ زنده سرعت خالص دانلود (Net Speed)
  - مانیتورینگ پهنای باند و سرعت ورودی خط اینترنت (Incoming Line Bandwidth)
  - نمایش حجم دانلود شده / حجم کل / حجم باقیمانده اپلیکیشن‌ها
  - ماتریس قطعات همزمان (Multi-Thread Chunks Matrix)
  - مودال افزودن تسک و محدودکننده سرعت (Speed Limiter)
