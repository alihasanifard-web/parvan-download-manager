## 🌟 قابلیت‌های کلیدی نسخه ۳.۰ (Key Features)

### ۱. موتور دانلود و بهینه‌سازی سرعت
- **⚡ شکستن پویای چانک‌ها (Dynamic Chunk Splitting & Stealing):** تقسیم مجدد بخش‌های باقیمانده از کندترین چانک‌ها بین کانکشن‌های آزاد در انتهای دانلود جهت جلوگیری دائمی از فریز روی ۹۹٪.
- **⚡ ۱۶ الی ۳۲ کانکشن همزمان (Multi-Thread Chunks):** قطعه‌بندی فایل‌ها بر مبنای هدرهای استاندار `Range: bytes` و شتاب‌دهی واقعی تا حداکثر کشش خط.
- **💾 نگاشت فایل در حافظه (Zero-Copy mmap):** مدیریت بهینه فایل‌های سنگین چند گیگابایتی با کمترین درگیری رم و دیسک.
- **🌐 تجمیع پهنای باند (Network Adapter Bonding):** تقسیم چانک‌های دانلودی میان چند کارت شبکه فعال (LAN + Wi-Fi).

### ۲. ابزارهای نسل جدید و انحصاری
- **🕷️ خزشگر و استخراج‌کننده جامع صفحات وب (Site Grabber):** پویش وب‌سایت‌ها تا عمق دلخواه و استخراج دسته‌بندی‌شده لینک‌های چندرسانه‌ای، آرشیوها و نرم‌افزارها.
- **📦 بازبین محتوای فایل‌های فشرده (Remote ZIP Inspector):** مشاهده محتوا، نام فایل‌ها و اندازه‌ها درون فایل‌های فشرده بزرگ بدون نیاز به دانلود کل فایل از طریق Range Request.
- **🎬 تعمیر و بازسازی ویدیوهای ناقص (Incomplete MP4 Fixer):** جابه‌جایی و بازسازی هوشمند اتم‌های `moov` و `mdat` در ساختار ISOBMFF تا ویدیوهای دانلودنشده نیز قابل پخش شوند.
- **▶️ پخش زنده استریم ویدیو (In-App Live Video Player):** دکمه پلی درون‌برنامه‌ای برای تماشای زنده ویدیوهای در حال دانلود با پاسخ استاندارد HTTP 206 Partial Content.
- **🔒 صندوقچه دانلودهای خصوصی (Private Vault):** تفکیک و قفل صف دانلودها با پین‌کد امنیتی و مخفی‌سازی فایل‌ها روی دیسک.
- **⚡ مینی‌ویجت شناور دسکتاپ (Floating Drop Target):** المان مدرن شیشه‌ای روی دسکتاپ جهت دراگ و دراپ لینک‌ها و دانلود بلادرنگ.
- **📊 سهمیه‌بندی و مانیتورینگ مصرف ترافیک (Quota Limiter):** تعیین سقف مصرف روزانه/ماهانه با کاهش خودکار سرعت یا توقف دانلود پس از اتمام حجم.
- **☁️ همگام‌سازی ابری صف دانلود (Cloud Sync / WebDAV):** تهیه نسخه پشتیبان و بازیابی صف دانلودها با سرورهای WebDAV و Nextcloud.
- **🤝 اشتراک شبکه محلی (LAN Mesh P2P):** کشف خودکار دستگاه‌های داخل وای‌فای از طریق UDP Broadcast و جابه‌جایی چانک‌های مشترک با سرعت گیگابیتی بدون مصرف اینترنت.
- **⚡ اتصال به سیدباکس‌های ابری (Debrid Engine):** تبدیل لینک‌های هاستینگ‌های کند به لینک‌های CDN پرسرعت اختصاصی.

### ۳. ضدتحریم، استریم و تورنت
- **🛡️ موتور ضد DPI و بای‌پاس فیلترینگ:** شکستن پکت‌های ClientHello TLS و ریزنگاشت DoH بدون احتیاج به پروکسی‌های سنگین خارجی.
- **🎬 دانلود استریم‌های HLS / M3U8:** دریافت همزمان سگمنت‌های تصویری و اسمبل خودکار در قالب فایل باکیفیت MP4.
- **🧲 کلاینت واقعی تورنت و مگنت:** ارتباط با تراکرهای P2P، اعتبارسنجی قطعات با هش SHA-1 و مدیریت کامل تورنت‌ها.
- **👻 استتار ترافیک (Stealth Tunnel / TLS Mimicry):** پدینگ بایت‌ها و تنظیم جیتر تصادفی برای گمراه‌سازی بازرسان شبکه.

### ۴. تجربه کاربری و یکپارچگی با ویندوز
- **🔔 آیکون تری ویندوز و اعلانات بومی (System Tray & Windows Toast):** کار مداوم در پس‌زمینه با اعلان‌های مدرن ویندوز ۱۰/۱۱ پس از پایان دانلود.
- **🖱️ منوی راست‌کلیک ویندوز اکسپلورر:** گزینه «Download with Parvan» در منوی کلیک‌راست فایل‌ها و پس‌زمینه ویندوز.
- **📋 ناظر هوشمند کلیپ‌بورد:** شناسایی خودکار آدرس‌های دانلود کپی‌شده در سیستم‌عامل.
- **🤖 ادغام کامل با ربات تلگرام (`@Parvan_mediabot`):** ارسال لینک از هر نقطه‌ای در جهان با موبایل و دانلود خودکار روی سیستم خانه.
- **🎨 طراحی لوکس OLED Dark Tech:** الهام‌گرفته از استانداردهای Obsidian با ترکیب رنگ‌های نئون فیروزه‌ای، امبر و زمردی.

## 🚀 راهنمای نصب و راه‌اندازی سریع

### استفاده از بسته نصبی دسکتاپ:
فایل نصبی ویزاردی `Parvan_Setup.exe` را اجرا کرده و مسیر نصب دلخواه را انتخاب نمایید. نرم‌افزار به صورت خودکار میانبرهای دسکتاپ و استارت‌منو را پیکربندی می‌کند.

### اجرای نسخه سورس‌کد:
```bash
git clone https://github.com/alihasanifard-web/parvan-download-manager.git
cd parvan-download-manager
pip install -r requirements.txt
python app.py
```
سپس پنل را در مرورگر یا وب‌ویو روی آدرس `http://127.0.0.1:9876` مشاهده فرمایید.
